# Student Grade Calculator

## Description

Student Grade Calculator is a beginner Python project that calculates a student's grade based on their marks.

## Features

- Accepts student marks as input.
- Calculates the student's grade.
- Displays the calculated grade.

## Requirements

- Python 3.x

## Installation

1. Install Python 3.x on your computer.
2. Create or open the `AI_Student_Project` folder.
3. Save the Python program in the project folder.

## Usage

1. Open a terminal in the project folder.
2. Run the Python program.
3. Enter the student's marks when prompted.
4. The program displays the grade.

Example command:

```bash
python calculator.py
```

## Example

```text
Enter student marks: 85
Grade: B
```
