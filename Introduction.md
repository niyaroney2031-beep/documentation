# Introduction

Python is a general-purpose programming language used for scripting, automation, web development, data analysis, education, and many other tasks. Before Python programs can run, the Python interpreter must be installed on the computer.

This documentation explains how to install Python on Windows 10 or Windows 11 using the official installer, confirm that the installation works, and resolve common setup issues. The steps are written for a beginner and use Windows PowerShell or Command Prompt.

## Software Requirements

- A computer running Windows 10 or Windows 11.
- An internet connection to download the installer.
- Permission to install software. On a managed computer, administrator approval may be required.
- A supported 64-bit Windows system is recommended for most current computers.
- A web browser to visit the official Python website.

Download Python only from the official website: [python.org/downloads/windows](https://www.python.org/downloads/windows/). Choose a current stable release offered for Windows. Avoid third-party download sites.

## What You Will Install

The Windows installer includes the Python interpreter and the `py` launcher. It can also install tools such as `pip`, which downloads and manages Python packages. The installer may offer an option to add Python to `PATH`, allowing the `python` command to work in a terminal.
