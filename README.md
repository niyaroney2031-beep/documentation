# Python Installation Guide

A concise guide to installing and verifying Python on Windows 10 or Windows 11.

## Documents

- [Introduction](Introduction.md): purpose, scope, and prerequisites.
- [Installation](Installation.md): download, install, and verify Python.
- [Frequently Asked Questions](FAQ.md): answers to common setup questions.

## Images

The `Images` folder is reserved for screenshots used in the documentation. Add your own screenshots there and link to them from the relevant Markdown page. Avoid including screenshots that show personal information, account details, or unrelated desktop content.

## Audience

This guide is intended for beginners installing Python on a personal Windows computer. Menu names can differ slightly between Python releases.
