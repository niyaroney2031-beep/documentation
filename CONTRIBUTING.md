# Contributing to the Python Student Project

Thank you for contributing to this Python student project.

## 1. How to Report an Issue

If you find a problem:

1. Open the project's issue section.
2. Describe the problem clearly.
3. Explain what you expected to happen.
4. Provide useful details about the problem.

## 2. How to Suggest a Feature

To suggest a feature:

1. Open the project's issue section.
2. Describe the feature you want to add.
3. Explain why the feature would be useful.
4. Keep the suggestion clear and simple.

## 3. How to Create a Branch

Create a separate branch before making changes.

Use a clear branch name, for example:

```text
feature-new-calculation
```

Make your changes in the new branch.

## 4. How to Make Changes

1. Create a branch.
2. Make the required changes.
3. Keep the changes simple and easy to understand.
4. Save your work.
5. Review your changes before submitting them.

## 5. How to Test Changes

Before submitting your changes:

1. Run the Python program.
2. Check that it works as expected.
3. Test the changed functionality.
4. Make sure there are no errors.

## 6. How to Create a Pull Request

After testing your changes:

1. Push your branch to the project repository.
2. Open a pull request.
3. Give the pull request a clear title.
4. Describe what you changed.
5. Submit the pull request for review.

## 7. Basic Coding Guidelines

- Write simple and readable Python code.
- Use clear names for variables and functions.
- Keep the code organized.
- Add comments when they are helpful.
- Avoid unnecessary code.
- Test your changes before creating a pull request.

## Thank You

Thank you for helping improve the project!
